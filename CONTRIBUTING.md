## Setup

In the Unity Version Control Window, elect to not include private files to check ins.

Unity VC Window > Settings > Pending Changes Options > Show Private Files [OFF]

## Branching Strategy
We will employ a feature based branching strategy.

Similar to how Sand of Souls was handled
